# AI News Scraper

Scrapes the latest AI-related news and discussions from Hacker News.

## What it does

- Fetches top stories from Hacker News
- Filters stories by AI-related keywords (GPT, LLM, Claude, neural, etc.)
- Displays title, score, and link for each story

## Requirements

```bash
pip install requests beautifulsoup4
```

## Usage

```bash
python ai_news_scraper.py
```
